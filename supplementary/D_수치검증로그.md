# 보충자료 D — 수치 전수 대조 로그와 AI 관여·인간 검수 명세

> 심사 요구 대응: "본문·표·그림·범례 수치의 전수 대조"와 "AI 보조 산출물의 인간 검수 절차·기록·오류율".

## 1. 수치 전수 대조 (기계 대조)

- 도구: `scripts/27_claims_crosscheck.py`. 원고의 데이터 기반 수치 주장을 claim 단위로 등재하고
  산출물(CSV·JSON·SQLite)에서 재계산한 값과 자동 대조한다. 반올림 표기는 반올림 허용오차로 비교한다.
- 결과(2026-09-06 실행): **총 123건 대조, 123건 PASS, 불일치 0건.**
  대상: §2.1 모수 7건, 표 1·§2.2 누락률 7건, §3.1 원창 장르 15건, §3.2 파생 장르·성향 20건,
  §3.3 원창 성향 19건, 표 3·표 4·§5 키워드 35건, 표 5·§6.1 작가 동학 7건, §6.2·그림 4 수용 집중 12건 등.
- 전체 목록: `outputs/claims_crosscheck.csv` (claim_id, 위치, 주장, 산출값, 판정).
- 이 대조기는 수정 과정에서 실제 오류를 검출·교정하는 데 사용되었다. 검출 사례: 2008–14년 애정
  구간 하한(84.5→84.1%), 다원 2025년 표기(6.98%→7.0%로 반올림 통일), 프리스트 작품 수의 모수
  명시(전체 37편 중 원창 35편 — 본문에 "원창 시장 기준" 명시 추가).
- 별도로, 적대적 자기 심사(`05_final/review_adversarial_20260906.md`)가 지적한 수치 불일치
  8건(N1–N8)은 전량 본 대조기의 대상으로 등재되어 수정 후 PASS 상태다.

  산출: `outputs/codebook_recomposition_check.csv` (보충자료 B 참조).

## 3. AI 관여 명세

- **AI 보조(Claude, Anthropic Claude Code 환경)가 수행한 작업:**
  데이터 수집(크롤링) 실행, 정제(파싱·dedup·5축 분해·DB 구축), 데이터 분석(집계·지표 산출),
  그래프 시각화(그림 1–4), 검증용 코드북과 검증 데이터 구축(수치 대조기·재조립 검증·표본 검수표).
  모든 산출은 `scripts/`의 결정론적 코드로 고정되어 프롬프트 없이 재실행 가능하다.
- **연구자(류호현)가 수행한 작업:** 연구 기획(연구 질문·설계·시기 구분·정책 연동 프레임),
  원고 집필, 데이터 표본 검수, 최종 판단·승인.
- AI 산출물이 원고에 반영되는 경로: AI가 스크립트·산출 CSV를 생성 → 기계 대조(1절)와
  재조립 검증(2절) 통과 → 연구자가 표본 검수(`outputs/codebook_sample_200.csv`, 200건 고정 시드)와
  원고 층위의 확인을 수행 → 반영. 수치가 코드 산출물 밖에서 원고에 진입하는 경로는 없다
  (모든 본문 수치는 claim 대조 대상).
