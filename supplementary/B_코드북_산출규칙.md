# 보충자료 B — 코드북: 분류·산출 규칙의 전수 명세

> 심사 요구 대응: "분류의 상호배타/다중라벨 여부, 분모, 가중치 변환식, 정규화, 무표기 처리 등
> 모든 산출 규칙의 명세와 검증표·오류율".

## 1. 원자료 필드와 5축 분해 규칙

플랫폼 목록의 `类型` 필드는 하이픈으로 연결된 단일 문자열이다
(예: `原创-纯爱-架空历史-仙侠-主受`, `衍生-言情-近代现代-东方衍生-女主`).

| 축 | 토큰 위치 | 값 공간(관측) | 결측 표현 |
|---|---|---|---|
| originality(원창성) | 1 | 原创 / 衍生 | 5토큰 구조가 아닌 문자열 전체를 `unclassified`로 격리 |
| orientation(성향) | 2 | 言情·纯爱·无CP·百合·多元 | 빈 토큰 허용 |
| era(시대) | 3 | 近代现代·架空历史·幻想未来·古色古香 등 | 빈 토큰 허용 |
| genre(장르) | 4 | 爱情·剧情·轻小说·仙侠·东方衍生 등 | 빈 토큰 허용 |
| perspective(시각) | 5 | 女主·主受·男主 등 | 빈 토큰 허용 |

- **다중 라벨은 존재하지 않는다.** 한 작품은 하나의 `类型` 문자열을 가지며, 각 축은 최대 1개 값이다.
  따라서 축 내부 값들은 상호배타적이고, 시장별·연도별 구성비의 합은 (결측 토큰 제외 시) 100%가 된다.
- **역방향 전수 검증(오류율):** 분해된 5개 필드를 `-`로 재조립해 원문과 대조한 결과, 분류층
  3,391,297행 전량이 완전 일치했다(일치율 100.0000%, 오류 0건). 미표기층 464,977행은 정의상
  5토큰 구조가 아니어서 분해 대상이 아니다. 산출: `outputs/codebook_recomposition_check.csv`
  (스크립트: `scripts/28_codebook_validation.py`).
- **표본 검수:** 고정 시드(20260906) 난수로 추출한 200건의 원문·분해 대조표를
  `outputs/codebook_sample_200.csv`로 제공한다. 검수 주체는 연구자(교수)이며 검수결과 기입란을 포함한다.

## 2. 분모 정의 일람

| 수치 | 분자 | 분모 |
|---|---|---|
| 시장 구성비(§2.1) | 각 층(原创/衍生/미표기) 건수 | 전체 3,856,274 |
| 시장별 장르 구성비(그림 1·2) | 해당 시장·연도·장르 건수 | 해당 시장·연도 총 건수(성향·장르 결측 포함) |
| 시장별 성향 구성비(그림 3, §3.3) | 해당 시장·연도·성향 건수 | 해당 시장·연도 총 건수(성향 미표기 포함) — 따라서 성향 5종 합이 100% 미만일 수 있음 |
| 키워드 장르 내 비중(표 3) | 해당 키워드 포함 제목 수 | 원창 애정 장르 총 1,962,010건 |
| 누락률(표 1) | 독립 수집에만 있고 연도 수집에 없는 work_id 수(신규 발표분 보정) | 독립 수집 파티션 총 건수 |
| 작가 데뷔율(§6.1) | 시기 내 최초 등장 작가 수 | 해당 시기 활동 작가 수 |
| 잔존율(§6.1) | 직전 시기 활동 작가 중 당기에도 활동한 수 | 직전 시기 활동 작가 수 |
| 적분 점유율(그림 4, §6.2) | 시기(또는 연도) 내 적분 상위 1%·10% 작품의 적분 합 | 해당 시기(연도)의 **원창 시장 전 장르 작품** 적분 총합 (표 5의 원창 애정 모수와 다름; 전체 작품 모수·원창 애정 모수로 바꾸면 P4 상위 1%가 각각 73.3%·70.7%로 변동) |

- 미표기층(12.1%)은 어느 시장에도 배정하지 않고 시장별 수치에서 제외한다(원고 §2.1의 근거 서술 참조).
- 가중치·정규화 변환은 사용하지 않는다. 모든 비율은 단순 건수비이며, 작품적분은 원값 그대로 합산한다.

## 3. 제목 키워드 규칙 (5장)

- 단위: 중국어 2–3자 연속 문자열(n-gram)의 전수 추출. 형태소 분석기를 쓰지 않으므로 겹침이 존재한다
  (예: `穿书后`가 폭증하면 `穿书`·`书后`도 함께 계수됨 — 표 4의 2019년 행은 대표형만 채택).
- 불용 처리: 단일 문자·숫자·기호·범용 기능어 연쇄를 불용자 목록으로 제거(구현: `scripts/21`).
- 신생 키워드 판정(표 4): 폭증 연도 건수 ÷ 직전 3년 평균 건수 = 성장배수. 절대 건수 하한을 함께
  적용해 소표본 배수를 배제한다. 산출: `outputs/v2b_yearly_title_keywords.csv`(배수 내림차순).
- 상위 키워드(표 3): 원창 애정 장르 제목 대상 빈도 상위 10위 전량 공개
  (`outputs/v2b_genre_title_keywords.csv`). 감정 어휘를 불용 처리하지 않았으며, 본문 §5.1의
  장치·감정 어휘군 구분과 합산(105,589 대 56,544)은 표 3의 공개 값에서 재계산 가능하다.

## 4. 작가 동학 정의 (6장)

- 작가 키: 목록의 공개 필명 문자열(`作者`). 필명 변경·동명이인은 식별 불가 — 한계로 명시.
- 시기: P1 2003–09 / P2 2010–16 / P3 2017–19 / P4 2020–23 / P5 2024–26(부분).
  경계는 3장의 변곡 국면(2010 정점, 2017→18 급락, 2020 팽창, 2024 분류 개편)에 대응한다.
- 활동 작가: 해당 시기·장르에 1편 이상 발표한 필명. 데뷔: 그 장르에서 최초 발표 시기가 당기.
  유입/이탈: 직전 시기 대비 집합 차. 잔존: 직전 시기와 당기 모두 활동.
- P5는 우측 절단의 영향을 받으므로 절대 규모 비교를 유보한다(표 5 각주·§6.1 말미).

## 5. 정책 연표 층위 구분 (4장·표 2)

각 행의 전거 층위를 (공식)=정부·판공실 원문/공보, (보도)=당대 언론, (연구)=학술 문헌으로 구분해
표기하며, 층위 간 승격(보도를 공식으로 표기하는 등)을 금지한다. 인용 URL의 접속 확인일은
참고문헌에 병기한다.
